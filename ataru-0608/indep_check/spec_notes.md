## (a) C* の点

### 式（読み）

固定した対応 M（席→場面の関係、又は伏せた位置）について、

- 一致を評価する席：見えている関係に対した席 i。q_i＝P_i^match(x_i)（x_i はその関係の見えている名前）。
- 各席の一致・不一致 Z を独立に引く。Pr(Z)＝Π q_i^{z_i}(1−q_i)^{1−z_i}。
- S0(M;Z,x)：不一致の席の対を外し、引数の対が欠けた親も外した残り（sme2017 の _grow がそのまま決める）を、
  sme2017 の局所の点（同じ名前 0.0005）と trickle-down（×8）で、全体の段（global）として採点した点の和。
- S_P＝Σ_Z Pr(Z)·S0(M;Z,x)。
- T(g)：g の全ての席に名前を与えて全部合わせた恒等の自己対応を、同じ採点で明示的に採点した点。
- Q_P＝2 S_P／(T(d)＋T(x))。

照合用の分布 P^match（委 41 ■4 (1) 805–807 行、41′ 1 912 行）：
- --match-eps 0：F は固定名に 1・他 0、H は q_H、U は b。
- --match-eps shared：値付けと同じ P（P_F＝(1−ε)δ_f＋εb、P_H＝(1−ε)q_H＋εb、P_U＝b）。
- q_H(x)＝(n_x＋α b(x))／(n＋α)、α＝1（委 41 ■3 800 行、照 §5 158 行）。
- 確率 0 の名前は候補にしない（q＝0）（委 41′ 1）。

## (b) 第二段の Δr

### 式（読み）

- 開示のあった試行で、記憶の全定義の F/H の席 i（scope all）について、M^{-i}＝席 i だけを一段薄くした記憶
  （F→H は履歴を残す、H→U は履歴を消す）。scope chosen（委 42⁗）は、その試行で選ばれて答えに使われた定義の席だけ。
- 各記憶で全定義をやり直す：照合（C*、総当たりの最良の M）→ S_P・T・Q → 門 → m・z → 選び → 答える席 → 分布 → 損。
  a・b・p̂ は予測前の値に固定（委 42′ 4、注 2 の 7）。
- 選び：z_d＝ln Q_d − Σ_j a_{k(j)} m_dj の大きい順 → 席数 n（F＋H）→ 新しさ。残った同点は印（古い版
  smeshared._definition_choice の N3 を z に替えた。a＝0 なら順は N3 と同じ）。全定義で Q＝0 なら背景。
- 門：支持 ≥ ceil(0.67·n)。支持＝場面の名前が固定名と同じ関係に対した F の席＋場面の名前が履歴にある関係に対した H の席
  （U は数えず、分母にも入れない）（委 41′ 3）。
- 答える席の分布：一つなら P_{d*}、複数なら等しい重みで混ぜる（委 42⁵ 2）。門を通る定義が無い・答える席が無いなら
  背景：形と階が分かれば絞った b、分からなければ p̂（委 42⁵ 1）。
- 損：top1 r＝−log₂ P(y)（P(y)＝0 なら L_of の退避符号の長さ、委 42″ 1）。0/ℓ：発話が y なら 0、違う・黙るなら ℓ(y)＝L_of(y)。
  mixture：p̃＝Σ π_k P_k(y)、π＝softmax(z)（温度 1）、候補が空なら背景。
- Δr_i＝r(M^{-i})−r(M)。負も 0 に丸めない（委 42′ 2）。
- 比べ用に rematch="fixed"（予測の時点の対応を固定して点と答えだけ直す＝委 42 ■3 の軽い近似）も持つ。
