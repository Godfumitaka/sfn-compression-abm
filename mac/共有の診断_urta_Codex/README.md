## 判断ごとの量

- `required_net_saving`：元が同化の判断の `(元の新規のK−元の選択のK)/λ`。同点では既存が残るので超える値が必要。新規が比較に無い場合、元が新規の場合、λ=0の場合は空欄。
- `saving_structure`・`saving_names`・`saving`：参照を引く前の節約の内訳と合計。
- `reference.a/b/c/d/e`：印・共有先の定義・部分・関係の対応・物の対応の費用。
- `r/e_sh/k_S/m_N/e_N`：共有する行数・その行の共有先の物の数・共有先の行数・変わる定義の行数・変わる定義の物の数。
- `net`：節約−参照。正の最大値を採用。最大値が0以下なら共有せず印1ビットを払う。
- `adjustment`：今の定義の費用に足す量。採用時は `−net`、非採用時は1。
- `source_ties`：正の差し引き最大値で同点の共有先をすべて残す。共有量・参照の表はその最小と最大。Eの費用は同じ。
- `source_U`・`excluded_U_N`：各共有先と、変わる定義のUの行の数。`eligible_sources` は共有する行が1本以上ある共有先の数。
- `net_memory_saving`：元の新規の記憶増分−共有符号での記憶増分。非採用時は印のため−1。
- `net_memory_saving_ratio`：上の節約を元の新規の記憶増分で割った割合。
- `gross_max`：各共有先の参照を引く前の節約の最大値。採用先の節約は `gross_selected_min/max`。
- `remaining_bits`：共有符号での新規と、その符号で選ばれた最小費用との差をλで割った値。λ=0または新規が比較に無い場合は空欄。同点の境目では既存が残る。
