## 用語（今日足したもの）

| 語 | 意味 |
|---|---|
| 言い直し | 場面で見えている関係と同じ中身の予測・主張。伏せ辺では絶対にない |
| B | 選んだ述語そのものが見えているときだけ埋めない穴埋めの直し（--fill-norestate） |
| C | 見えている述語を候補から外してから選ぶ穴埋め（比べの腕） |
| 渡し | 墓石の子の席の代わりに、場面の見えている関係を親の行の子として使うこと。子の元の述語が見えているときだけ行う（v3.5） |
| audit/・control/ | 結果用のブランチの中の、調べの報告と判断・切り替えの置き場所 |
| 出どころ | 主張が、投影・生きている行の穴埋め・墓石の穴埋めのどれから出たか |
