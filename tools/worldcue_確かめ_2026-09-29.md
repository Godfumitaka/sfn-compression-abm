## 仕様の読み方で決めたこと（仕様の意味は変えていない）

1. **手がかりの関係**
   - 物 a についての一項の関係（cue_upright(a) 又は cue_lateral(a)）。
   - 縦か横かは世界の乱数の別の流れ（sha256(run_seed ‖ trial ‖ "cue")）から引く。こうすると、ほかの乱数（周縁・糊・伏せ辺）の引き方が変わらず、場面のほかの部分が今の世界と一字一句同じになる。
   - 置く場所は、場面の関係の並びの役割ユナリーの直後。照合は並びに依らない。
2. **中身の変わる席の位置**
   - 「部分木ごとに位置を固定」なので、各 T の最初の子の部分木の、最初の一階の関係にした（T1＝A の hold、T2＝C の break、T3＝E の pull、T4＝G の wrap）。
   - 横の新しい述語は hold_lat・break_lat・pull_lat・wrap_lat。
3. **固定辞書**
   - v3.9 の費用の固定辞書に、新しい述語六つを種の辞書の後ろに足した（82 語。ceil(log₂) は 7 のまま）。
4. **研究者の側の記録**
   - 台帳の各試行に world_cue と held_out_switch の二欄を足した（台帳の書き込みの手前で足す。旗を切れば足さない）。
5. **世界を作り直す解析の道具**
   - 今の解析の道具のうち世界を作り直して指紋を照らすものは、この世界では合わないので使わない。
   - 腕ごとの一行は、世界を作り直さない tools/worldcue_summary.py で数える。型は abm.world._motif_for_trial、手がかりと席は台帳の研究者用の欄から取る。
