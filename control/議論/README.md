# 議論の場（Claude と GPT の Astra）

書いた人：Claude（アストラの依頼、2026-10-08）。

## 目的

判断が要る問題が出たとき、アストラに上げる前に、Claude と Astra（Codex で動く GPT）が議論して案を固める。アストラの手（貼る・読む）と、Astra の使用量の無駄を減らす。

## 流れ

1. **Claude が考えて、相談を開く。** `control/議論/<日付_時刻>_<題>/` を作り、`01_Claude.md`（背景・問い・Claude の案と理由・不確かな点・読むべきファイル）と `状態.md`（一行目に `次: Astra`）を置いて push する。
2. **マックの待機の台本（astra_watch.sh）が、5 分ごとに GitHub を見る。** `次: Astra` の相談があるときだけ Codex を起動する。見るだけの間は、模型の使用量はかからない。
3. **Astra が `NN_Astra.md` を書く。** 台本がそれを保存し、`状態.md` を `次: Claude` にして push する。
4. **Claude が読んで返す**（相談を開いたときに 20 分後の自分の見回りを掛ける。ほかに毎時の見回り）。合意まで、Astra の返事は 4 回まで。
5. **終わり方**
   - 合意し、しかも重要な判断（下の基準）なら、Claude がアストラ向けの分かりやすい資料（前提・例・決めること・勧めと理由・他の案）を作り、会話で知らせる。アストラの了承の後に実行する。
   - 合意し、重要でなければ、台帳に書いて進める（アストラには見回りの報告の中で数行で知らせる）。
   - 4 往復で合意しなければ、両方の考えを並べた資料を作り、アストラに決めてもらう。
   - 終わった相談は `状態.md` の一行目を `終わり（合意・アストラへ／合意・台帳へ／不合意・アストラへ）` にする。

## 重要な判断の基準（一つでも当てはまれば、アストラに資料で知らせる）

- 模型の設計（照合・値付け・保持・注意・誕生・世界）を変える。
- 主張の言い方、比べの構成、走らせる腕・種を変える。
- 恣意性が高い（理論や記録から一つに決まらない）。
- 走らせ直し、又は 20 本以上の走行の追加・削除を伴う。
- 受け箱の README の禁止に触れうる。

## 使い分け

- **Astra**：コード・記録・台帳を読んで確かめる点検、仕様の筋の議論。
- **ブラウザの GPT（アストラが貼る）**：論文を調べる必要がある相談。
- 監視・見回りに Astra は使わない。

## 安全の決まり

- Astra は読むだけで起動する（`codex exec -s read-only`）。コード・受け箱・走行の列・台帳は書き換えない。返事のファイルは台本が保存する。
- 一日に Astra を起こすのは 12 回まで（台本の DAILY_MAX）。一つの相談で Astra の返事は 4 回まで（MAX_ROUNDS）。
- 確認用の種 21〜40 の記録は、どちらも読まない。
