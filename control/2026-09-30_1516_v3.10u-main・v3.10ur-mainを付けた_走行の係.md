## 変更点

1. --u-struct（tools/ustruct.py）。
   - U の子を持つ親の照合の候補で、U の子が見えている関係 C に当てはまってよいことにした。
   - 守ること（照合の候補の規則として）。
     - 物には当てはまらない（関係と物の区別）。
     - U の席の行と C の引数の数が同じこと。
     - U の席の行の引数も C の引数と対にし、親の候補に入れる。行の引数が定義の関係なら関係と、物なら見えている物と。種類が違えば当てはまらない。既存の物・関係の対応と食い違えば、その親の候補は採られない。
     - 一つの候補の中で、同じ左が二つの右に、又は二つの左が同じ右に当たるなら、その候補は作らない（同じ席を複数の位置へ当てはめない）。
     - U の席の名（忘れた名）は見ない。親自身の名前の条件は今のまま。U の席そのものは照合の候補にも支持の分子・分母にも入らない（グラフに置かないのは今のまま）。
     - 見えていない ID への当てはめは今のまま。
   - U の席の観察（m1 の席の履歴）：親が写れば、その親の同じ引数の位置の子を U の席の対応先にし、子が見えていればその述語を観察として足す（覚え直しのきっかけ）。
     - tools/histrole.py の親の子の規則を、U の席については階を問わず使う。高階の U の席も、子の ID の組ではなくこの規則にした（同じ席を二重に観察しないため）。
     - 親が無い・写らない・子が見えないときは足さない。同じ物の組の関係をまとめて拾わない。
   - この旗で照合が変わるのは、U の子が見えている関係に当たる候補だけ。それ以外の候補は、今と同じ形で作る。
2. --relearn-init（tools/relearninit.py）。
   - U の席が観察を受けて覚え直す（U→H）とき、その観察一回だけの新しい H（名前 1 回）の記録の初期値に、次を入れる（誕生の初期の成績と同じ形）。
     - 同じ観察を H で答えた場合と U で答えた場合の書換ビット（一致なら 0、違えば観察した名の ℓ）。
     - ℓ と H・U の答えは、同じ時点の p̂ と同じ場面で出す。
   - 古い履歴・点数は復活させない（世代は今のとおり新しい）。
   - B の採点の累計（R_B）には足さず、side の kind＝"relearn_init" に別に書く（未来の予測の成功とは数えない）。
   - 覚え直しは、登録（m1 の観察）と会計（v3.8 の D-10 の観察）のどちらで起きたものにも入れる。
   - 観察が一つでない覚え直しには初期値を入れず、数だけ数える（下の走行では 0 回）。
3. 支持の三分類（tools/answerlog.py、--dump-answers の記録に列を足した。門の決まりは変えない）。
   - 列 sel_vis・sel_hid・sel_none：選ばれた定義の名前を持つ F・H の席を、写しで分けた数。見えている関係に対応した／親から伏せられた位置（見えていない ID）に対応した／対応先が無い。
   - 列 sel_vis_match：見えている関係に対応した席のうち、その関係の名が F の固定名・H の履歴の名（回数 1 以上）に一致した数。
   - 列 cand_tri：選ばれなかった候補の上位 5 つの「支持の割合:見えている/伏せられた/無い/一致」。
