## 次に必要な最小の材料

**デスクトップ原本の0始まり681行だけを、末尾の改行まで含めた未変更のバイト列で保存してpushする必要がある。** 全種の台帳や種2、新しい走行は必要ない。マック側の該当原文は [圧縮した681行](2026-10-03_注意の選択_Codex2_デスクトップ行照合_マック681行.jsonl.gz) に保存した。展開後は元の100,950 Bと完全に同じで、上記のマックの行sha256で検算済み。

デスクトップ側で必要なのは、JSONとして読み直して再出力することではなく、元の一行のコピー。例えば次で取り出せる（模型の実行を伴わない）。

```python
import gzip
import hashlib
from itertools import islice
from pathlib import Path

ledger = Path.home() / 'n3prod/n3_w1_A_L50/ledgers/cells/f0.5000_th2.1000_vt0.3842_first_order/seed001.jsonl.gz'
with gzip.open(ledger, 'rb') as source:
    raw = next(islice(source, 681, 682))
assert hashlib.sha256(raw).hexdigest() == 'b4854535757844e099efcf7e13e29e660c75f55f1517f36eb498d5a4ac63f80a'
Path('seed001.line681.jsonl').write_bytes(raw)
```

この原文の入手後に、元のバイトの差と欄の値の差を別に示し、模型の値と書式を区別する。配列順の違いを自動的に書式の差と扱わず、乱数状態や記憶で意味を持つ順序は保持する。これは差の説明のための点検であり、元の全バイト一致の合格条件を変更するものではない。
