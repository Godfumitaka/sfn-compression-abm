SME は、二つの場面の関係と物の対応を、関係のつながりを保ちながら探す手順である。
MH（対応の仮説）は、物又は関係一本どうしを対応させる候補である。
まとまり（kernel）は、上の関係の MH と、それが要求する引数の対応を一緒にしたものである。
trickle-down は、上の関係の対応についた点を、下の引数の対応へ渡す計算である。
一対一は、一つの物・関係を複数の相手に写さず、逆向きにも重複させない条件である。
親子の整合（parallel connectivity）は、対応した親の同じ引数位置で、子も対応する条件である。
F は固定した名前、H は名前と回数の履歴、U は名前を忘れた席である。
N3 は、対応した名前・引数・親子のつながりを、二つのグラフの大きさで割って定義を選ぶ値である。
A・C・D は忘却の保持価値を測る規則で、A は席自身の課題、C は最終回答への影響、D は名前の使用の強さを使う。
以下の「時間」は、作業の時間と機械を待つ時間を分けて記す。工数の幅は見積もりであり、測定値ではない。

今回の成果は資料の所在、接点、測定、未決定事項、関門と作業順の案である。SME の版、H/U の点、世界の作りを採用・決定していない。本番の走行は行っていない。

### F/H/U と欠けた位置

現行の H は、今の履歴で回数 1 以上の**どの名前とも**照合できる（`v39.py:274–276,305–311`）。固定 F の名前が同じ、H の許容集合に名前がある、という条件が通常の述語の同一性の前にある。H の名前を最頻一つへ絞る、複数 MH に分ける、集合を一つのラベルとして扱う、のどれを採るかで対応と支持は変わる。選択していない。

U は通常の `v39_graph` では関係一覧から外すが、`--u-struct` は別の控えに構造を残し、名前の条件なしで親の位置を使う。新しい MH の網へ構造専用の U ノードを作る案と、通常の網の外に U の補助対応を残す案がある。名前の一致の点、U が体系性の点を伝えるか、U だけからまとまりを開始できるかは独立に指定する必要がある。U は原典 SME の仮定ではない。

相手の伏せ位置には名前も引数もない。今は親からその位置の ID へ対応できる例外がある。SME の完全な子の整合をそのまま要求すると、その親を落とす。未知の位置の仮ノードを置く案、今の欠けた子の例外を MH 構築に残す案、完全入力の照合だけ論文と同じにし部分入力の投影を別の契約にする案を記録する。基の側で以前伏せられた位置と、種類の控え `strictpc.KINDS/RELPOS/LEFT_REL` も対象である。正解の名前を仮ノードに入れない。

### 共通の配置：四葉の二つの経路

一つの配置案として、四葉の部分木ごとに `p(u,a), q(a,v), r(u,b), s(b,v)` を用意する。入口 u と出口 v を共有する二経路で、四つの物の接続位置は固定する。八葉では四葉ブロックを二つ置く。ブロックごとに内部物 a,b を持ち、ブロック間の入口・出口を共有するかは未決定。下の測定はブロック間を共有しない案（計 8 個の骨組みの物）である。

物と関係の ID は場面ごとに不透明な ID へ付け替える。今の `opaque_id(run_seed,trial,role)` が使える。関係の数、親の引数順と木、述語、答えの真理表、変種の確率、開示の乱数は配置の処理で変えない。散らす処理を元の世界生成の外側、お店又は v4 の名前切替の内側へ一度だけ差し込む案で、世界の包みを二重に作らない。

この二経路では、どの一階の葉を一本伏せても、両端の物はもう一本の見える葉に現れる。自作の八葉・十五関係の例で、八通り全てについて、全体と提示の物はともに 8 個、伏せた葉の両端で提示から消えた物は 0 個だった（`common_layout_visibility.json`）。先の「完全に別の物の組」の例の消える物の問題は、この配置の一階の検査では起きなかった。実世界の補助関係と二階の伏せまでの確認は関門に残す。

未決定は、二ブロック間の入口・出口の共有、今の a,b をどの入口・出口に残すか、つなぎ・周縁・のり・役割ユナリーの接続先である。**お店のシールは今のまま** `sig_n/sig_e(元の a)` と `attach(シール,一番上の関係)` に保つ。そのため元の a の ID を配置に残す設計が必要で、シールを新しい内部物へ付け替える処理は見積もりに含めない。これらの指定がないうちは生成コードを実装しない。

### v4 の名前が競合する役割の小例：保証する方法と範囲

以下は**照合の単体検査用の入力案**であり、本番の世界に名前の重複や新しい型・変種を追加する案ではない。八葉のうち一本を伏せ、見える七本の名前を両場面で同じにする。物は u,a,b,v,o。a,b 等の文字に意味はなく、全て場面ごとに付け替える。

| 見える関係 | 場面 A | 場面 B |
|---|---|---|
| 二経路の入口（同名二本） | fold(u,a), fold(u,b) | fold(u,a), fold(u,b) |
| 名前が競合する葉二本 | break(a,v), break_b(b,v) | break(b,v), break_b(a,v) |
| 内部の物を結ぶアンカー | carry(o,a) | carry(o,a) |
| その他の共通葉 | lift(v,o), press(o,u) | lift(v,o), press(o,u) |
| 伏せた答え（評価側のみ） | hold(a,v) | hold_b(a,v) |

見える名前の集合と本数は `fold×2, break×1, break_b×1, carry×1, lift×1, press×1` で同じ。関係名ごとの ID と入力行順を保って、break と break_b の**物の接続だけ**を変える。carry と共参照する内部物の経路が手がかりの役割を定める。名前一覧だけを入力する道具には二場面が区別できない。

五物の全ての一対一の対応（120 通り）を自作の台本で列挙した。順付き引数と名前を全て保つ対応は、A の定義→A の場面が 1 個、B→B が 1 個、A→B と B→A はともに 0 個。物の接続を使うと二つを区別できることを、この単体入力の範囲で確認した。定義の八本目に対応する hold 又は hold_b を置き、写った `(a,v)` を投影すれば期待する答えが得られる、という第一段の検査案になる。データは `v4_role_fixture.json`。

**高階の位置だけで解けないことの保証は、検査入力の契約が必要。** 上の保証した入力は一階の照合単体入力で、競合する二葉の高階の役割位置を与えない。現行 `--answer-gap` も通す案では、穴の ID と carry の ID だけを引数に持つ同じ `cause(穴,carry)` を両場面に置き、競合する break/break_b の位置情報を入れない。この検査用の親は 既存の述語 cause を使い、生成世界の木を置換しない。

一方、**本番の順序付きの高階木をそのまま全て提示すれば、根からの引数位置の経路で各葉の役割を区別できる。** その入力で「物のつながりを使わない限り解けない」を保証したとは言えない。単体検査で高階の役割情報を省く案を許すか、本番の木を含む別の競合例が必要かは未決定。高階を省くのは模型の世界を変える処理ではなく、単体関門の入力を限定する提案である。上の全列挙は新しい SME の回答関門を通したものではない。

### 第二段で v4 の手がかりの利用を確かめる量

正しい定義を与える第一段では、型×既存変種の定義の写しから、左右それぞれの切替葉を順に伏せる。自分の答えの席、他方の手がかりの席、物の対応、支持、投影の名前と順付き引数を記録する。既存の二階の伏せと、名前が競合する単体例も含める。

学習・忘却を動かす第二段では、答えの F/H/U の出どころ、正しく答える定義の有無、切替二席が区別を保持したか、問われた席と手がかり席がどの関係に写ったか、物の順の一致、支持、棄権の理由を数える。型・変種・正解は研究者の側の記録だけで判定する。成績の上下は採否の関門にしない。

### 補助：v4 の片方向の対照

左の葉だけを課題にし、右を手がかりとする対照では、左の述語を変種によらず A の値に固定、右は従来どおり切り替える。葉数・高階の木・既存の型と変種を増やさない。右の切替が左の答えを変えない状態で、手がかりの対応と不要な利用を数える。

左だけを問う指定を本番の伏せの抽選へ入れるか、保存した定義を与える試験だけにするか、学習の課題も左に限定するかは未決定。これは補助の追加作業であり、主への採用条件に含めない。

## 6. 決めずに残す点

## 8. 作業順と期限の見込み

作業順の案は、(1) **必須の A の順付き採点を独立の小例でそろえる**、(2) 基準版と MH・点・入力の契約を固定し、原典例題と整合の部品を確認、(3) v4 の役割競合の単体関門、(4) 共通配置と F/H/U・穴の接続、(5) 正しい定義でお店・v4 の第一段、(6) 学習・忘却・診断・再生の第二段、(7) 一本の全走行で時間を更新、(8) 比較の格子・版・同一機械・種順を固定、である。片方向対照はこの後の補助。成績を見て版を選ぶ工程は含めない。

10/3 昼から 10/5 夜は約二日半。担当人数と稼働時間は未指定。一人一日 8 時間なら三日で最大約 24 時間、一日 12 時間なら約 36 時間という条件別の数え方で、深夜の連続作業を前提にしない。

未決定事項が早く指定されるなら、A の引数順の直しと小例は約 2〜4 時間、普通の順序付き関係に限った MH・整合・点の部品と v4 の競合例は約 16〜28 時間の先行範囲。この範囲を「原典の全入力型・F/H/U・部分入力・全解析・両世界の二段の関門を全部通過」と読み替えない。片方だけでも上表の全接続と関門は 56〜104 時間の工数幅であり、一人の 10/5 夜までの全通過は約束できない。

10/5 夜に関門を通っていない部品は論文の仕事へ回す、10/8 に関門と比較の準備が全部通った場合のみ新版を主にし、通らなければ今の N3 で凍結する、という期限を残す。採用版・成績の解釈・未指定の接続は決めていない。今回は見積もりと単体の測定で区切り、模型の実装に進んでいない。
