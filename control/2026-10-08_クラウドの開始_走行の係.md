## 1. 確かめ（15:55）
- aws sts get-caller-identity：利用者 sfn-runner（arn:aws:iam::<口座番号>:user/sfn-runner）。
- 地域：us-east-1。
- aws s3 ls s3://sfn-abm-results-astra1008/：通った（空）。バケット名は手順書の例どおり。
- 鍵の権限で、できないと分かったこと：
  - SSM の値の読み取り：AMI は、ec2 describe-images で Canonical（099720109477）の公式 Ubuntu Server 24.04 LTS の最新を引く形に替えた。
  - 価格の API と Cost Explorer：費用の見込みは、時間単価の表（prices_us_east_1.json。公表価格の記憶から置いた値で、要確認）× 立ててからの時間で出す。実際の費用は請求の画面で確かめてほしい。
  - IAM：機械に S3 の役割を付けられない。そのため、機械の上の出力は、デスクトップが D: に持ってきて、デスクトップから S3 に上げる（aws_fetch_run.sh）。クラウドの機械に鍵は置かない。

  - 機械の上の sha256 と一致を確かめる。
  - デスクトップから S3（s3://sfn-abm-results-astra1008/cloud_runs/calib_<本>/）に上げる。
  - 小さい記録を GitHub（ataru-0608/cloud_runs/）に上げる。
  - クラウドで終わった時刻を ~/cloud/calib13_done.tsv に書く。
  - 13 本を全部持ってきたら、機械を消す。失敗した本があれば、消さずに待つ。
